# PhonePe Pulse Analytics — Interview Notes

## Project Overview

This project analyzes PhonePe Pulse digital payment data using Python, SQL, and Streamlit.

The objective is to understand transaction trends, payment categories, geographical patterns, user growth, and merchant growth.

## Technologies Used

- Python
- Pandas
- SQL
- Streamlit
- Plotly
- Pytest
- Git & GitHub

## Key Analysis Areas

### 1. Transaction Trends
Analyze transaction count and transaction value across years and quarters.

### 2. Category Analysis
Compare transaction categories based on transaction volume and total transaction value.

### 3. Geographic Analysis
Identify states with higher transaction volumes and transaction values.

### 4. User Analysis
Analyze registered user growth over time.

### 5. Merchant Analysis
Analyze registered merchant growth over time.
